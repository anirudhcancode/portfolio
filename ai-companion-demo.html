Project 04

AI Companion

3
Platforms
Problem

Digital tools tend to be reactive by default — they wait to be asked, and forget the moment you close the app.

Mission

Designing for genuine continuity — memory, tone, and context that build over time instead of resetting with every session.

Overview

Most AI chat apps forget everything between sessions. This one builds a living understanding of the user over time — not just a log of past messages, but a synthesized picture of who they are, updated continuously as the relationship develops.

It doesn't wait to be asked. If someone mentions a person, a commitment, or a goal in passing conversation, it catches it and acts on it — logging it, remembering it, following up later — the way a genuinely attentive friend would, without turning every message into a form to fill out.

Goal progress is woven into natural, narrative check-ins rather than rigid trackers or streak-shaming — reflecting real shape over weeks, not punishing a single off day. No invented deadlines, no dashboard pressure. Progress is witnessed, not graded.

It reads tone and context to calibrate how it responds — knowing when to lean in and when to back off — while staying clearly in its lane. It's not a therapist and doesn't pretend to be one.

Health, music, and daily context all feed into how it shows up — not as separate dashboards, but woven into how it talks to the user, so it feels like one continuous relationship rather than a set of disconnected features.

A fully custom visual identity and interaction language, built from scratch rather than assembled from off-the-shelf chat UI patterns.

Under the Hood

Built on a Node/Express backend with a tool-orchestrated Claude reasoning loop, semantic memory via pgvector, and live integrations for health, music, weather, news, and web search.

Status

Where things stand

The conversation engine, memory system, and emotional calibration are live and running in daily use across iOS, Android, and web. The visual layer — including context-responsive theming — is still evolving; the current release uses a single refined palette while the adaptive version is in development.

Includes user-controlled data privacy — full conversation export, memory deletion, and history clearing — built in from the start.
